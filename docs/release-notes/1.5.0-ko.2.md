## 요약

OTA 펌웨어 다운로드가 `http_perform:ESP_ERR_HTTP_CONNECT`로 실패하던 문제를 수정했습니다. 다운로드 경로를 wolfSSL 기반 `HttpDownloader`로 옮겼습니다.

## upstream 변경 사항

없음 (한국어 포크 단독 릴리스).

## 한국어 버전 변경 사항

### 수정

- **OTA 다운로드 연결 실패 수정**: 설정 → 시스템 → 업데이트에서 새 버전은 조회되지만 다운로드 단계에서 `http_perform:ESP_ERR_HTTP_CONNECT`로 중단되던 문제를 수정했습니다.
  - 업데이트 확인은 `HttpDownloader`(wolfSSL), 다운로드는 자체 `esp_http_client`(mbedTLS)로 서로 다른 TLS 스택을 쓰고 있었습니다. 이 패키지에 포함된 mbedTLS는 TLS 1.3이 빈 스텁으로 컴파일돼 있어(`freeink-sdk` `SecureClient.h`) 릴리스 CDN에 연결하지 못합니다.
  - 다운로드도 `HttpDownloader::fetchUrl`로 통일했습니다. GitHub → CDN 리다이렉트 처리가 내장돼 있습니다.
  - SD로 내려받은 뒤 `firmware_flash::flashFromSdPath`로 기록하는 2단계 구조는 그대로입니다. X4의 efuse-blk-rev 오탐을 피하기 위한 것입니다.

`-DFREEINK_NET_WOLFSSL=1`은 1.5.0 병합에서 처음 들어왔습니다. 그 이전(1.3.0-ko.1)에는 확인·다운로드가 모두 mbedTLS라 증상이 없었습니다.

### 부수 효과

`esp_http_client`와 mbedTLS 인증서 번들 의존이 빠지면서 `firmware.bin`이 191,152 B 줄었습니다.

| | `firmware.bin` | 6.25 MB 한도 대비 |
|---|---|---|
| 1.5.0-ko.1 | 6,041,152 B | 512,448 B 여유 |
| 1.5.0-ko.2 | 5,850,000 B | 703,600 B 여유 |

### 기술 세부

- `OtaUpdater::installUpdate`에서 `esp_http_client_config_t` + `download_event_handler` + `DownloadCtx`를 제거하고 `HttpDownloader::fetchUrl(url, DataCallback)`로 대체했습니다. 콜백이 `false`를 반환하면 전송이 중단되므로 SD 쓰기 실패 시 즉시 빠져나옵니다.
- 진행률은 콜백 안에서 누적 바이트로 갱신합니다. Content-Length 헤더 대신 `checkForUpdate`가 가져온 릴리스 자산 크기(`otaSize`)를 기준으로 쓰며, 잘린 다운로드 검사(`short_body`)도 그대로 동작합니다.
- 이벤트 핸들러 전용이던 `OtaUpdater::setLastError`와 `esp_http_client.h` / `esp_crt_bundle.h` 의존을 제거했습니다.

### 업데이트 방법

이 버전은 OTA 다운로드 자체를 고치는 것이라, 1.5.0-ko.1에서 OTA가 실패했다면 SD 카드로 설치해야 합니다.

- **SD**: `firmware.bin`을 SD 카드에 복사 → 설정 → 시스템 → SD카드 펌웨어 업데이트
- **OTA**: WiFi 연결 후 설정 → 시스템 → 업데이트 (1.5.0-ko.2 이후부터 정상 동작)
- **웹 플래셔**: https://crosspoint.kr/flasher
- 설치 가이드: https://crosspoint.kr/install
