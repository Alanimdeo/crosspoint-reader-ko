## 요약

리더에서 문단 중간의 텍스트가 통째로 빠지던 문제를 수정했습니다. X3에서 기본 리더 글꼴을 쓸 때 주로 나타났습니다.

## upstream 변경 사항

없음 (한국어 포크 단독 릴리스).

## 한국어 버전 변경 사항

### 수정

- **문단 중간 텍스트 누락 수정**: 긴 문단에서 한 줄 분량의 글자가 사라지고, 사라진 자리에 여백도 남지 않던 문제를 수정했습니다.
  - upstream 1.5.0의 소프트 플러시가 원인 조건이었습니다. 블록의 토큰 수가 임계치(내장 CSS 사용 시 320)를 넘으면 조판을 미리 한 번 수행하면서 마지막 미완성 줄은 다음 청크로 넘깁니다.
  - 단어 단위 줄바꿈 경로는 인덱스만 계산하므로 토큰이 남지만, 글자 단위 줄바꿈(`characterWrap`, 한국어 기본값) 경로는 줄을 채우며 토큰을 앞에서 지웠습니다. 넘겨야 할 마지막 줄의 토큰이 이미 삭제된 뒤라 그 줄이 소실됐습니다.
  - upstream이 한글을 음절 단위 토큰으로 쪼개므로 한국어 문단은 임계치를 자주 넘습니다. X3의 뷰포트가 528 px(X4는 480 px)라 억제되는 줄에 더 많은 글자가 실려 X3에서 두드러졌습니다.
  - 이제 줄을 채울 때 커서만 옮기고, 줄이 실제로 출력된 뒤에만 토큰을 잘라냅니다.

### 내부

- 섹션 캐시 버전을 41 → 42로 올렸습니다. 1.5.0-ko.2 이하에서 만들어진 캐시에는 누락된 줄이 그대로 저장돼 있으므로 다시 생성해야 합니다.
- 글자 단위 줄바꿈 경로에 `TextBlock::valid()` 검사를 추가했습니다. 단어 단위 경로에는 원래 있던 검사로, 아레나 할당 실패 시 빈 블록을 페이지에 넣는 대신 힙 수치와 함께 기록합니다.
- 문단 들여쓰기(U+3000)가 블록당 한 번만 적용되도록 했습니다. 소프트 플러시로 같은 블록이 여러 번 조판될 수 있습니다.
- `gh_release`에 시리얼 로그를 다시 켰습니다(약 27 KB). `default`는 `LOG_LEVEL=2`입니다. 용량이 빠듯할 때 껐던 것인데, 이 문제는 릴리스 빌드에서 진단이 불가능했고 현재 약 670 KB 여유가 있습니다.

### 업데이트 방법

- **OTA**: WiFi 연결 후 설정 → 시스템 → 업데이트
- **SD**: `firmware.bin`을 SD 카드에 복사 → 설정 → 시스템 → SD카드 펌웨어 업데이트
- **웹 플래셔**: https://crosspoint.kr/flasher
- 설치 가이드: https://crosspoint.kr/install

업데이트 후 해당 책의 캐시가 다시 생성되면서 첫 진입이 평소보다 느릴 수 있습니다.
