## 요약

upstream **v1.5.0** 을 병합한 한국어 버전입니다. 큰 책이 몇 분 걸리던 첫 색인이 백그라운드로 넘어가 수 초 만에 열리고, 오프라인 사전과 책갈피가 추가되었습니다. 한국어 전용 글꼴·조판 기능은 모두 그대로 유지했습니다.

> [!IMPORTANT]
> **섹션 캐시 포맷이 v26 → v41 로 바뀌어 모든 책이 한 번 재색인됩니다.** 첫 열기가 평소보다 느린 것은 정상입니다.
>
> **1.2.0-ko.x 에서 바로 올라오는 경우 설정이 초기화됩니다.** upstream 이 1.5.0 에서 레거시 `settings.bin` 마이그레이션을 제거했습니다. 1.3.0-ko.x 를 거쳐 오셨다면 설정은 유지됩니다.
>
> **이번 버전은 단일 OTA 설치가 불가합니다.** `firmware.bin` 이 6.87 MB 로 순정 CrossPoint OTA 파티션(6.25 MB)을 약 307 KB 초과합니다. 잠긴 X4 는 2단계 설치(순정 CrossPoint 로 OTA → SD 카드로 KO 플래시)를 이용해 주세요.

## upstream v1.5.0 주요 변경 사항

### 기능
* **점진적 섹션 색인**: 큰 챕터의 첫 페이지가 즉시 표시되고 나머지는 읽는 동안 백그라운드로 색인됩니다. 리더를 나가도 색인된 페이지가 보존되어 재진입 시 바로 열립니다.
* **오프라인 사전**: SD 카드 `/dictionaries` 에 StarDict 사전을 넣으면 단어를 선택해 뜻풀이를 볼 수 있습니다.
* **책갈피**: 리더 메뉴에서 책갈피를 추가·삭제하고 목록에서 이동할 수 있습니다. 확인 버튼 길게 누르기에 할당할 수도 있습니다.
* **다음 책 추천**: 책을 다 읽으면 끝 페이지 화면에서 기기에 있는 다른 책을 추천합니다.
* **선택 팝업**: 선택지가 3개 이상인 설정은 항목을 하나씩 순환하지 않고 대화상자로 열립니다.
* **빠른 복귀 절전 화면**: 절전 시 읽던 화면을 그대로 두고 달 아이콘만 표시해 즉시 복귀합니다.
* **Wi-Fi 개선**: 저장된 네트워크 자동 재연결, 숨겨진 SSID 수동 추가.
* **KOReader 동기화 확장**: 기기에서 계정 생성, 문서 매칭 방식, 메타데이터 전송, 스마트 동기화.
* **OPDS 개선**: 서버 여러 개 등록, 다운로드 폴더와 파일 이름 형식 지정.
* **EPUB `<ruby>` 지원**, CSS `text-decoration` 확장, `<br>` 처리와 목록 불릿 정렬 개선.
* **RoundedRaff 테마** 추가.

### 성능 / 수정
* 렌더링·메모리 최적화로 페이지 넘김이 개선되고, 복잡한 EPUB 에서 발생하던 메모리 부족 크래시와 CSS 파서 버그가 수정되었습니다.
* 다른 기기용 펌웨어를 설치하려 하면 차단하고 안내합니다.

### 내부
* SDK 가 `open-x4-sdk` → `freeink-sdk` 로 교체되었습니다.

## 한국어 버전 변경 사항

### 수정
* **자간**: upstream 이 CJK 단어를 글자 단위 토큰으로 분할하도록 바뀌면서 한국어 글자 단위 줄바꿈 조판이 음절마다 공백을 넣던 문제를 수정했습니다. 붙는 글자는 하나의 런으로 묶어 그려 글꼴 설계 그대로의 자간을 유지합니다.
* **줄바꿈 밀도**: 위 수정 과정에서 줄 채우기 판정이 어절 사이 간격을 하나 적게 계산해, 한 줄에 글자가 하나씩 더 들어가고 어절 간격이 최소값까지 눌리던 문제를 수정했습니다. 판정 기준을 1.3.0-ko 와 동일하게 되돌려 줄바꿈 위치와 페이지 밀도가 1.3.0-ko 와 일치합니다.
* **배터리 표시**: 완충 상태에서 91% 로 표시되던 문제를 보정했습니다. SDK 의 전압-퍼센트 곡선이 4.136V 이상에서만 100% 를 반환하는데 완충 셀이 분압·ADC 오차로 약 4.06V 로 읽히는 것이 원인이었습니다. 곡선 상단만 100% 로 확장하고 하단은 그대로 두어 저전력 경고 정확도는 유지합니다.
* **뒤로 짧게 파일 탐색기**: 이 옵션이 EPUB·TXT 리더에서 동작하지 않던 문제를 수정했습니다. 각주를 보는 중에는 설정과 무관하게 뒤로 짧게가 각주 복귀에 먼저 쓰입니다.
* **설정 > 리더**: 줄 간격·화면 여백·문단 정렬·내장 스타일·하이픈·문단 간격·단락 들여쓰기·글자 단위 줄바꿈·안티앨리어싱 항목이 목록에서 보이지 않던 문제를 수정했습니다.

### 유지된 한국어 전용 기능
* `UnifiedFontFamily` / `SdFontFamily` 글꼴 시스템 (SD 카드 `.epdfont` 런타임 로딩)
* 기본 EPUB 글꼴 KoPub 바탕, UI 시스템 글꼴 선택 + Pretendard 글리프 폴백
* 합성 볼드(Synthetic Bold) 렌더링, 자간 조절
* 단락 들여쓰기 / 글자 단위 줄바꿈 (기본 ON), 한국어 줄 간격 1.00 / 1.20 / 1.40배
* 하이픈은 글자 단위 줄바꿈이 꺼져 있을 때만 적용
* 읽기 시간 누적·초기화, 자동 페이지 넘김, 길게 눌러 페이지 점프
* X4 2단계 OTA 경로 (SD 다운로드 후 플래시)

### 내부
* upstream 의 `.cpfont` SD 글꼴 엔진을 제거하고 한국어 `.epdfont` 엔진을 유지했습니다. 이에 따라 upstream 의 "텍스트 설정" 화면과 "글꼴 관리"(폰트 다운로드), 웹 UI `/fonts` 페이지는 포함되지 않습니다. 텍스트 옵션은 리더 메뉴의 **읽기 옵션**에서 조정합니다.
* 한국어·영어 두 언어만 포함합니다 (플래시 용량).
* 신규 문자열 61개를 모두 번역해 한국어 fallback 0 을 유지합니다.
