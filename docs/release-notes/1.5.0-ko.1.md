## 요약

**1.5.0-ko.0 의 OTA 불가 문제를 고친 긴급 수정입니다.** 기능 변경은 없고, UI 글꼴(Pretendard)의 한글 수록 범위를 줄여 펌웨어를 순정 OTA 파티션 안에 다시 넣었습니다.

> [!IMPORTANT]
> **1.5.0-ko.0 을 쓰고 계시면 이 버전으로 업데이트해 주세요.** 1.5.0-ko.0 은 `firmware.bin` 이 6.87 MB 로 순정 CrossPoint OTA 파티션(6.25 MB)을 넘겨서, 전체 플래시를 거치지 않은 기기에서는 OTA 와 SD 카드 업데이트가 모두 `TOO_LARGE` 로 거부됩니다.

## 무엇이 문제였나

OTA 와 SD 카드 업데이트는 **app 파티션만** 기록하고 파티션 테이블은 건드리지 않습니다. 그래서 순정 CrossPoint 에서 OTA 로 한국어 펌웨어에 올라온 기기는 지금도 **순정 6.25 MB 테이블**을 그대로 갖고 있습니다.

| | app0 / app1 크기 |
|---|---|
| 순정 CrossPoint | 0x640000 = 6,553,600 B |
| 한국어 포크 (`partitions.csv`) | 0x6A0000 = 6,946,816 B |

1.3.0-ko.1 까지는 `firmware.bin` 이 6.46 MB 라 양쪽 모두에 들어갔습니다. 1.5.0-ko.0 은 6.87 MB 로 커져서 순정 테이블 기기에서만 거부되었고, USB 가 막힌 기기는 전체 플래시라는 우회로조차 없었습니다.

파티션 테이블 자체는 1.5.0 병합에서 바뀌지 않았습니다 (`partitions.csv` 는 1.2.0-ko.15 이후 동일).

## 변경 사항

### 수정
* **UI 글꼴 한글 범위 축소**: Pretendard 10pt 가 한글 음절 11,172자를 모두 담아 1,070 KB 를 쓰고 있었습니다. KS X 1001 완성형 2,350자로 제한해 **828 KB** 를 회수했습니다.

| | `firmware.bin` | 순정 6.25 MB 대비 |
|---|---|---|
| 1.5.0-ko.0 | 6,869,392 B | 315,792 B 초과 |
| **1.5.0-ko.1** | **6,041,152 B** | **512,448 B 여유** |

본문 글꼴 **KoPub 바탕은 한 바이트도 바뀌지 않았습니다** (한자 4,620자 포함 그대로). 읽기 화면 렌더링과 섹션 캐시는 영향이 없습니다.

### 알려진 제약

KS X 1001 은 현대 한국어 표기를 사실상 전부 덮지만, 빠지는 8,822자(`뷁`·`똠` 같은 옛한글·의성어 조합)는 **UI 에서 표시되지 않습니다.** 메뉴 레이블에는 나오지 않지만 **책 제목이나 파일명**에는 나올 수 있습니다.

전체 한글이 필요하시면 이 릴리즈에 첨부된 `.epdfont` 를 SD 카드에 넣고 **설정 > 화면 > 시스템 글꼴**에서 선택하세요.

| 파일 | 크기 |
|---|---|
| `pretendard_10_regular.epdfont` | 1.06 MB |
| `pretendard_10_bold.epdfont` | 1.10 MB |

SD 카드의 `/fonts` 또는 `/.fonts` 에 복사하면 목록에 나타납니다.

### 내부
* 한국어 내장 글꼴 재생성 스크립트 `lib/EpdFont/scripts/convert-korean-builtin-fonts.sh` 추가. 기존 헤더는 임시 명령으로 만들어져 재현이 불가능했습니다. KoPub 을 이 스크립트로 다시 생성해도 글리프 데이터가 바이트 단위로 동일함을 확인했습니다.
* KS X 1001 구간 생성기 `lib/EpdFont/scripts/ks_x_1001_intervals.py` 추가.
* `docs/firmware-size-budget.md` 갱신 — 남은 여유 512 KB, 다음 감축 후보 정리.

## 1.5.0 기능은?

1.5.0-ko.0 의 모든 기능이 그대로 있습니다 — 점진적 섹션 색인, 오프라인 사전, 책갈피, 다음 책 추천, 선택 팝업, Wi-Fi 자동 재연결, KOReader 동기화 확장, OPDS 다중 서버. 자세한 내용은 [1.5.0-ko.0 릴리즈 노트](https://github.com/crosspoint-reader-ko/crosspoint-reader-ko/releases/tag/1.5.0-ko.0)를 참고하세요.

섹션 캐시 버전은 v40 그대로입니다. 1.5.0-ko.0 에서 이미 재색인했다면 다시 하지 않습니다.
