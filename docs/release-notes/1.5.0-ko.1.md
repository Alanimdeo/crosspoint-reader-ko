## 요약

1.5.0-ko.0에서 OTA와 SD카드 업데이트가 거부되던 문제를 수정했습니다. UI 글꼴(Pretendard)의 한글 수록 범위를 KS X 1001 완성형으로 줄여 `firmware.bin`을 6.25 MB OTA 한도 안으로 되돌렸습니다. 기능 변경은 없습니다.

1.5.0-ko.0을 쓰고 있다면 이 버전으로 업데이트하세요.

## upstream 변경 사항

없음 (한국어 포크 단독 릴리스).

## 한국어 버전 변경 사항

### 수정

- **OTA / SD카드 업데이트 거부 수정**: 1.5.0-ko.0의 `firmware.bin`이 6,869,392 B로 순정 CrossPoint app 파티션(0x640000 = 6,553,600 B)을 315,792 B 초과해, 전체 플래시를 거치지 않은 기기에서 `TOO_LARGE`로 거부되던 문제를 수정했습니다. OTA와 SD 업데이트는 app 파티션만 기록하고 파티션 테이블은 바꾸지 않으므로, OTA로 한국어 펌웨어에 올라온 기기는 순정 6.25 MB 테이블을 유지합니다.
- **UI 글꼴 한글 범위 축소**: Pretendard 10pt가 한글 음절 11,172자 전체(1,070 KB)를 담고 있던 것을 KS X 1001 완성형 2,350자로 제한해 828 KB를 회수했습니다.
  - 본문 글꼴 KoPub 바탕은 바이트 단위로 무변경입니다(한자 4,620자 포함). 읽기 렌더링과 섹션 캐시(v40)에 영향 없습니다.

| | `firmware.bin` | 6.25 MB 한도 대비 |
|---|---|---|
| 1.5.0-ko.0 | 6,869,392 B | 315,792 B 초과 |
| 1.5.0-ko.1 | 6,041,152 B | 512,448 B 여유 |

### 제약

KS X 1001에서 빠지는 8,822자(`뷁`, `똠` 등 옛한글·의성어 조합)는 UI에서 표시되지 않습니다. 메뉴 레이블에는 나오지 않지만 책 제목이나 파일명에는 나올 수 있습니다.

전체 한글이 필요하면 이 릴리스에 첨부된 `.epdfont`를 SD 카드의 `/fonts` 또는 `/.fonts`에 넣고 **설정 → 화면 → 시스템 글꼴**에서 선택하세요.

| 파일 | 크기 |
|---|---|
| `pretendard_10_regular.epdfont` | 1,116,117 B |
| `pretendard_10_bold.epdfont` | 1,151,115 B |

### 기술 세부

- KS X 1001 완성형은 EUC-KR 2바이트가 모두 `0xA1`–`0xFE`인 영역입니다. Python `euc_kr` 코덱은 UHC 확장 8,822자도 인코딩하므로 인코딩 가능 여부만으로는 판별되지 않고, 바이트 범위로 걸러야 합니다.
- 2,350자는 U+AC00–U+D7A3에 흩어져 있어 연속 구간 1,613개로 쪼개집니다. interval 테이블이 552 B에서 19,884 B로 늘지만 비트맵이 932,858 B에서 226,349 B로 줄어 순감 828,329 B입니다. 구간 이진탐색 깊이는 6단계에서 11단계로 늘어납니다.
- 한국어 내장 글꼴 재생성 스크립트 `lib/EpdFont/scripts/convert-korean-builtin-fonts.sh`를 추가했습니다. 기존 헤더는 임시 명령으로 생성돼 재현 경로가 없었습니다. 이 스크립트로 KoPub을 다시 생성해 글리프 데이터가 동일함을 확인했습니다.
- KS X 1001 구간 생성기: `lib/EpdFont/scripts/ks_x_1001_intervals.py`
- `partitions.csv`는 1.2.0-ko.15 이후 변경 없습니다.

### 업데이트 방법

- **OTA**: WiFi 연결 후 설정 → 시스템 → 업데이트
- **SD**: `firmware.bin`을 SD 카드에 복사 → 설정 → 시스템 → SD카드 펌웨어 업데이트
- **웹 플래셔**: https://crosspoint.kr/flasher
- 설치 가이드: https://crosspoint.kr/install
