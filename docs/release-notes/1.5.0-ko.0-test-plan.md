# 1.5.0-ko.0 기기 테스트 계획

upstream `v1.5.0` 병합 결과물의 기기 검증 체크리스트.

## 빌드 상태

| 환경 | Flash | 비고 |
|------|-------|------|
| `default` | 99.2% | |
| `gh_release` | 98.7% | `firmware.bin` 6,868,768 B |
| `sticky` (S3) | 97.0% | |

clang-format 위반 0건, `korean.yaml` 439/439 자체 번역.

**플래시 크기**: `firmware.bin`이 순정 OTA app 파티션(6,553,600 B)을 약 307 KB 초과합니다.
잠긴 X4는 2단계 설치(순정 CrossPoint로 OTA → SD 카드로 KO 플래시)가 필요합니다.
`CP_HYPHENATION_LANGS=0`과 시리얼 로그 제거는 이미 적용된 상태이며, 추가 절감은 기능 삭제가
필요합니다. 배경: `docs/firmware-size-budget.md`

## 플래싱

서브모듈이 `open-x4-sdk` → `freeink-sdk` 로 교체되었습니다.

```bash
git submodule sync && git submodule update --init --recursive freeink-sdk
pio run -e default -t upload && python3 scripts/debugging_monitor.py
```

롤백용으로 1.3.0-ko.1 바이너리를 SD 카드에 준비해 두세요.

## 테스트 전 준비

| 항목 | 변경 |
|------|------|
| 설정 저장 | `JsonSettingsIO` → `PersistableStore`. 기존 `settings.json`은 그대로 읽힘. **1.2.x `settings.bin` 마이그레이션은 삭제됨** |
| 섹션 캐시 | v26 → **v39**. 전체 자동 재색인 |
| 진행률 | 페이지 번호 → 콘텐츠 오프셋 기반 |

`.crosspoint/`를 지운 클린 상태와 기존 캐시 유지 상태, 두 경로 모두 확인.

## 1. 한국어 기능 회귀 (최우선)

### 1.1 폰트

- [ ] `customFontPath` 빈 상태 → 본문이 KoPub 바탕으로 렌더링
- [ ] 설정에 upstream Font Family(NotoSerif/NotoSans) 선택기 없음
- [ ] 설정 > 리더 > 글꼴 → `.epdfont` 목록 (`/fonts`, `/.fonts`, 패밀리별 하위 폴더)
- [ ] SD 폰트 선택 후 재부팅해도 유지, 설정 목록에 현재 폰트명 표시
- [ ] 설정 > 화면 > 시스템 글꼴 → UI 전체 교체 + Pretendard 글리프 폴백
- [ ] 한자 다수 문서에서 글리프 깨짐 없음
- [ ] Bold 없는 SD 폰트에서 synthetic bold 적용

### 1.2 조판 / 자간

`SdFontFamily::getTextDimensions`의 combining-mark 계산을 upstream 신규 `combiningMark::Anchor`
API로 옮겼고, `layoutCharacterWrap`을 네 차례 수정했습니다(캐시 v37→v38→v39→v40→v41).

- [ ] **자간이 글꼴 설계값대로** (음절 사이가 벌어지지 않음)
- [ ] **줄바꿈 위치가 1.3.0-ko 와 동일** (같은 책·같은 설정에서 각 줄의 마지막 글자가 일치)
- [ ] 글자 겹침 없음
- [ ] 양쪽정렬에서 어절(공백) 사이만 늘어나고 오른쪽 여백이 맞음
- [ ] 공백 없는 긴 한자 문장도 줄이 오른쪽 끝까지 채워짐
- [ ] 한글 + 영문 혼용 문장의 영문 단어 간격 정상
- [ ] `characterWrap` 기본 ON, 아무 글자에서나 줄바꿈, **하이픈 미삽입**
- [ ] `characterWrap` OFF + 하이픈 ON → 영문 하이픈 동작
- [ ] `paragraphIndent` ON → 첫 줄 들여쓰기 1회만 (문단 간격 OFF 조합에서도)
- [ ] 줄 간격 좁게/보통/넓게 = 1.00 / 1.20 / 1.40, SD 폰트로 바꿔도 동일

### 1.3 캐시 무효화 + 위치 유지

- [ ] `paragraphIndent` / `characterWrap` / 리더 폰트 / 화면 회전 각각 토글 → 재색인 후 읽던 위치 유지

### 1.4 리더 메뉴 / 조작

- [ ] 리더 메뉴에 누적 읽기 시간 표시, "읽기 시간 초기화" 동작
- [ ] 읽기 옵션이 하위 액티비티로 열리고 Back으로 메뉴 복귀
- [ ] 읽기 옵션에서 여러 설정 변경 후 메뉴 종료 → **재레이아웃 1회만**
- [ ] 자동 페이지 넘김 중 상태 바 제목이 분당 페이지 수로 바뀌고, 자동 절전 안 걸림
- [ ] 각주 진입 후 Back 짧게 → 각주에서 원위치 복귀 (내비게이션 옵션보다 우선)
- [ ] **뒤로 짧게 파일 탐색기** OFF: 짧게=홈 / 길게=파일 탐색기
- [ ] **뒤로 짧게 파일 탐색기** ON: 짧게=파일 탐색기 / 길게=홈 — EPUB·TXT·XTC 모두

## 2. upstream 1.5.0 신규 기능

- [ ] 설정에 "글꼴 관리"(폰트 다운로드) 없음

## 7. 병합 중 판단 사항 (검토 요청)

| # | 판단 | 이유 |
|---|------|------|
| 1 | upstream cpfont 엔진 삭제, 한국어 `.epdfont` 유지 | 사용자 지시 (46c01385과 동일 방침) |
| 2 | `TextSettingsActivity`/`TextSettingsPreview` 삭제 | Family/Size 탭이 cpfont 레지스트리 의존, ReaderOptions로 대체 가능, 플래시 초과 |
| 3 | `JsonSettingsIO` 삭제 → upstream `PersistableStore` | upstream이 흡수. 부작용: 1.2.x `settings.bin` 마이그레이션 상실 |
| 4 | `fontSize` enum → upstream `fontPointSize` | upstream 코드가 광범위 의존. 한국어 폰트 선택은 영향 없음 |
| 5 | 신규 upstream 언어 6종 미포함 | fork 정책(en+ko) + 플래시 예산 |
| 6 | Finnish 하이픈을 `CP_HYPHEN_LANG_FI`로 게이팅 | 한국어 플래시 게이팅 체계 유지 |
| 7 | 한국어 "다음 챕터 silent indexing" 삭제 | upstream 백그라운드 점진 색인이 상위 호환 |
| 8 | `CP_HYPHENATION_LANGS=0`을 default/rc/slim/sticky로 확대 | 미적용 시 app 파티션 초과로 빌드 실패 |
| 9 | 섹션 캐시 v41 | v37 한국어 플래그 추가, v38·v39 자간 수정, v40 잉크박스 측정 복원, v41 줄 채우기 gap 수 복원으로 재무효화 |
| 10 | 사전 화면의 SD 폰트 prewarm 호출 제거 | cpfont advance table 전용 API. `SdFont`는 자체 캐시 |
| 11 | 한국어 OTA 2단계 경로 유지 | X4 efuse-blk-rev 오탐 회피가 존재 이유 |
| 12 | Back 내비게이션을 세 리더에 인라인 유지 | 각주 복귀 우선순위 + 읽기 타이머 갱신이 필요해 `handleBackNavigation` 미사용 (EPUB/TXT) |
